# Store graphics requirements

LG frequently rejects submissions due to **wrong icon/background sizes**. Export PNG files at **exact** resolutions from Seller Lounge for your target SDK version.

## Placeholders in this repo

| File | Purpose |
|------|---------|
| [`../../icon.png`](../../icon.png) | App icon (replace with 130×130 or required size) |
| [`../../assets/splash.png`](../../assets/splash.png) | Background / splash (replace per Seller Lounge spec) |

## Typical assets (verify in Seller Lounge before export)

- **Icon** — small launcher icon (often 130×130 px for webOS)
- **Large icon** — launcher/detail
- **Background** — home / detail banner (1920×1080 or as specified)
- **Screenshot** — 1920×1080 captures from real TV (no emulator UI chrome)

## Capture tips

1. Run app on TV at 1920×1080
2. Capture: Login, Live browse, Player, Movies grid, Series detail
3. Avoid black frames; show recognizable UI chrome
4. Do not include third-party copyrighted posters in marketing shots unless licensed
